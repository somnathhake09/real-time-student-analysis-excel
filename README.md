# Real-Time Student Performance Analysis — Excel

## 📊 Project Overview

An Excel-based student performance analysis project focused on data cleaning, performance analysis, lookup functions, Pivot Tables, KPI cards, and data visualization.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Nested IF
- COUNTIF
- AVERAGEIF
- VLOOKUP
- XLOOKUP
- Conditional Formatting
- Pivot Tables
- KPI Cards
- Data Visualization

## 🔍 Analysis Performed

- Cleaned and prepared student data
- Created weighted final scores
- Applied Nested IF for grade classification
- Created Pass/Fail analysis
- Identified at-risk students
- Performed improvement analysis
- Used COUNTIF, AVERAGEIF, MAX, MIN and LARGE
- Used VLOOKUP and XLOOKUP for data retrieval
- Created Pivot Tables for student analysis
- Created charts and KPI cards for visualization

## 📈 Dashboard

The project includes visual analysis using:

- Bar Chart
- Pie Chart
- Column Chart
- KPI Cards
